## [NutriScale — IoT Meal Tracking System](https://github.com/nabeelsyed14/nutriscale)

**Solo Project**

IoT-based dietary tracking platform combining computer vision, embedded hardware, and nutritional analysis.

The system identifies food items using AI while nutritional values are retrieved from a verified local database to reduce unreliable generated outputs.

### System Components
- Raspberry Pi edge processing
- Load cell-based weight measurement
- Camera-assisted food recognition
- Local nutritional database (~8,900 foods)
- ML-assisted dietary trend analysis

### Engineering Focus
- Edge AI
- Sensor fusion
- Hardware/software integration
- Local-first inference pipeline

`Raspberry Pi 5` `HX711` `Flask` `Random Forest` `Ollama` `Gemini`
